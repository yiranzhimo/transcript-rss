大家好，欢迎收看 Streamline Solopreneur 的周五总结。我是你们的主持人乔·卡萨博纳，今天我想和大家分享一些想法。2026年9月25日，我正在考虑把一切都烧个精光。我稍后会写一篇更深入的文章，但本周我突发奇想，决定把我的个人网站 casabona.org 从 WordPress 转换成静态文件网站。这个网站已经用了 WordPress 超过二十年，如果在一年前，要在两天内完成这样的转换几乎是不可能的。要将一个网站转换、清理，并建立重定向或归档结构，确保成千上万的链接不会失效，需要大量的规划、时间和精力，以及反复测试。而我却能相当自信、快速地完成这件事，而且我自己付出的努力并不多。这些是其中的关键要素。
我一直在思考，是否应该重新开始，但不破坏现有的一切，这或许并不是“烧个精光”这个词的恰当用法。但几周前，我在日记里写到我的邮件列表：我是不是应该干脆全部烧掉，从头再来？就像我的 WordPress 网站一样，邮件列表里积攒了多年的“外壳”和技术债务。列表里有我做 WordPress 开发员时期的联系人，有我早年播客时期的人，那时我的播客还叫别的名字，也包括赞助指导的日子。有多少人真正关心我现在在讲的内容？
我觉得这个问题值得深入探讨。
我常常担心沉没成本谬误。你不想继续投资于一个不奏效的东西，但你也并不想在还没搞清楚它是否有潜力之前就过早地全部推倒重来。
把 cabo.org 从 WordPress 转移出去，我考虑了两年，但从时间投入的角度来看，一直不值得。而 Claude Code AI 让这件事变得非常简单，它几乎完成了所有工作，我只做了抽查、检查、修正计划，并完成了一部分架构设计，但所有繁琐、耗时的工作——从搭建新网站的代码，到编写迁移脚本，再到创建重定向并测试这些重定向——都由它完成了。
邮件列表的问题我思考了几个月，但今天它并不比过去更容易解决，因为我需要和我的受众沟通，弄清楚邮件通讯的正确方向，以及什么内容真正能引起他们的共鸣。AI 无法告诉我这些，尽管有些人可能会这么说。
所以，是的，我正在考虑烧掉一些东西，但不是为了烧而烧，也不是如果这会让我花更多时间，反而得不偿失。你们怎么看？欢迎通过 streamlinedfeedback.com 联系我，注意是带 d 的 streamlinedfeedback.com。你可以发文字或语音留言，我甚至可能在节目中播放。
